\section{Objective}

This document provides a pragmatic execution roadmap from project setup to production-ready MVP based on finalized requirements. The roadmap is designed to:

\begin{itemize}
    \item Deliver working software in incremental, testable chunks
    \item Prioritize core financial flows that provide immediate value
    \item Minimize risk through early validation of critical paths
    \item Enable parallel workstreams where dependencies allow
\end{itemize}

% INCREMENT PLAN

\section{Increment Plan}

\subsection{Increment 1: Foundation \& Identity}

\textbf{Focus:} Project infrastructure and authentication layer

\textbf{Deliverables:}
\begin{itemize}
    \item Repository structure with monorepo or multi-repo setup
    \item CI/CD pipelines for frontend and backend
    \item Database schema baseline with migrations
    \item Authentication (login, logout, password change)
    \item RBAC middleware for Member, Worker, Admin roles
    \item Basic landing page with registration form UI
\end{itemize}

\textbf{Exit Criteria:}
\begin{itemize}
    \item Users can register, login, and access role-appropriate pages
    \item RBAC prevents unauthorized endpoint access
    \item CI/CD deploys to staging on merge
\end{itemize}

\subsection{Increment 2: Deposit \& Withdrawal}

\textbf{Focus:} Core financial flow for savings

\textbf{Deliverables:}
\begin{itemize}
    \item Deposit request API and UI
    \item Worker processing interface
    \item Member confirmation flow
    \item Withdrawal request with notice period validation
    \item Transaction ledger with proper accounting
    \item Member dashboard showing balances
\end{itemize}

\textbf{Exit Criteria:}
\begin{itemize}
    \item Complete Request $\rightarrow$ Process $\rightarrow$ Confirm cycle works
    \item Ledger balances are accurate
    \item Withdrawal rules enforced
\end{itemize}

\subsection{Increment 3: Loan Lifecycle}

\textbf{Focus:} Loan application, approval, and repayment

\textbf{Deliverables:}
\begin{itemize}
    \item Loan eligibility calculation (3-cap system)
    \item Loan application form and API
    \item Guarantor request and approval workflow
    \item Admin loan approval/rejection
    \item Worker loan disbursal and member confirmation
    \item Installment recording
\end{itemize}

\textbf{Exit Criteria:}
\begin{itemize}
    \item Member can apply for loan within eligibility
    \item Guarantor workflow functions correctly
    \item Loan states transition correctly through lifecycle
\end{itemize}

\subsection{Increment 4: Donations \& Disputes}

\textbf{Focus:} Donation management and error handling

\textbf{Deliverables:}
\begin{itemize}
    \item Donation form with fund type selection
    \item Donation fund tracking (Operating, Lending, Zakat, Sadaqah)
    \item Dispute raising mechanism
    \item Admin dispute resolution workflow
    \item Default settlement waterfall implementation
\end{itemize}

\textbf{Exit Criteria:}
\begin{itemize}
    \item Donations correctly categorized and tracked
    \item Disputes freeze transactions and alert admin
    \item Settlement waterfall executes correctly
\end{itemize}

\subsection{Increment 5: Polish \& Release}

\textbf{Focus:} Dashboards, hardening, and release preparation

\textbf{Deliverables:}
\begin{itemize}
    \item Member dashboard with all summaries
    \item Worker dashboard with pending queues and SLA indicators
    \item Admin dashboard with approvals, alerts, and settings
    \item Audit log viewer for admin
    \item Localization (English/Bengali) completion
    \item Security hardening and penetration testing
    \item Documentation and training materials
\end{itemize}

\textbf{Exit Criteria:}
\begin{itemize}
    \item All dashboards functional and accurate
    \item No critical/high security vulnerabilities
    \item System ready for production deployment
\end{itemize}

\section{Readiness Checklist}

Before development begins, the following must be complete:

\subsection{Documentation Readiness}
\begin{itemize}
    \item[$\square$] Business Requirements Document approved
    \item[$\square$] Software Requirements Specification approved
    \item[$\square$] Functional Requirements Document approved
    \item[$\square$] API Contract Specification approved
    \item[$\square$] Database Schema Design approved
    \item[$\square$] Test Plan agreed by engineering and operations
\end{itemize}

\subsection{Infrastructure Readiness}
\begin{itemize}
    \item[$\square$] Source control repositories created
    \item[$\square$] CI/CD pipeline templates ready
    \item[$\square$] Development environment provisioned
    \item[$\square$] Staging environment provisioned
    \item[$\square$] Database instances created (dev/staging)
    \item[$\square$] Environment variables documented
\end{itemize}

\subsection{Team Readiness}
\begin{itemize}
    \item[$\square$] Development team assigned
    \item[$\square$] Roles and responsibilities defined
    \item[$\square$] Communication channels established
    \item[$\square$] Sprint cadence agreed
\end{itemize}
