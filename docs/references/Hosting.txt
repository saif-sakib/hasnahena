# 🏗️ Final Architecture Documentation

## 1. The Core Tech Stack
*   **Frontend:** Next.js (App Router) + React + shadcn/ui + Tailwind CSS + TypeScript
*   **Backend:** Go (Golang) — *Using standard library or a lightweight router like Chi/Gin.*
*   **Future Microservice:** Java (Spring Boot) — *Strictly for banking/financial transactions later.*

## 2. Infrastructure & Hosting (The "Free Tier" Master Plan)

### 🖥️ Frontend Hosting: Vercel
*   **Why:** Vercel created Next.js. It offers seamless GitHub integration, edge caching, and zero-config deployments.
*   **Free Tier:** Generous "Hobby" plan. 100GB bandwidth, excellent performance. Totally free.

### ⚙️ Backend Hosting: Fly.io (or Koyeb/Render)
*   **Why:** Go compiles down to a tiny, standalone binary. This makes it incredibly cheap and fast to host.
*   **The Fly.io Caveat:** Fly.io is fantastic, but they recently changed their free tier. You *must* attach a credit card, and they give you $5 of free credit a month (which covers a small Go app). 
*   **Alternative (100% Free):** If you do not want to put in a credit card right now, use **Koyeb** or **Render.com**. Both have excellent, permanent free tiers for Go APIs.

### 🗄️ Database: Neon (PostgreSQL)
*   **Why:** Neon is "Serverless Postgres". It separates compute from storage, meaning it spins up instantly and scales effortlessly. It also gives you branching (like Git, but for your database).
*   **Free Tier:** 0.5 GB storage, 1 project. Perfect for MVP.

### 🖼️ Image & Media Storage: Cloudinary
*   **Why:** Storing images in a database is a bad idea, and Vercel/Fly instances are ephemeral (they delete local files when they restart). Cloudinary hosts your images and optimizes them for the web automatically.
*   **Free Tier:** 25 monthly credits (1 credit = 1,000 image transformations or 1GB storage). You will likely never hit this limit during MVP.

### 🌐 Domain Name: Namecheap
*   **Why:** Affordable, reliable, and includes free WHOIS privacy. 
*   **Cost:** ~$10/year (This is your only upfront cost).

## 3. The Missing Pieces (Completing the "Everything" Setup)
To have a fully functional SaaS or application, you need two more tools. Here are the best free-tier options:

### 🔐 Authentication: Clerk (or Auth.js)
*   **Why:** Building secure login, password reset, and social auth (Google/Apple) from scratch is a massive waste of time. 
*   **Option A (Clerk):** The best Auth service for Next.js. Free tier allows up to **10,000 monthly active users**.
*   **Option B (Auth.js / NextAuth):** 100% free, open-source. You host it yourself inside Next.js and connect it to your Neon Database.

### ✉️ Transactional Emails: Resend
*   **Why:** You will need to send "Welcome" emails, password resets, or notifications. 
*   **Free Tier:** **3,000 free emails per month**. Built specifically for Next.js and React developers (integrates perfectly with `react-email`).

## 4. How Everything Connects (Data Flow)

Here is how your system will talk to itself in production:

1.  **User visits `yourdomain.com` (Namecheap)** -> DNS points to **Vercel**.
2.  **Vercel** serves the Next.js Frontend (React/shadcn/Tailwind).
3.  User clicks "Upload Profile Picture". Next.js sends the image directly to **Cloudinary**. Cloudinary returns a secure Image URL.
4.  User fills out a form and clicks "Save". Vercel (Next.js) sends a JSON request to your **Go API** hosted on **Fly.io / Render**.
5.  Your **Go API** validates the request, executes business logic, and saves the data (along with the Cloudinary Image URL) into your **Neon PostgreSQL** database.
6.  *Future Step:* When the user clicks "Transfer Money", your Go API will forward that specific request securely to your highly secured **Java backend**.

## 5. Development & Deployment Workflow

To make your life easy, set up your development environment like this:

*   **Monorepo vs Multi-repo:** Create two separate GitHub repositories.
    *   Repo 1: `my-app-frontend` (Next.js)
    *   Repo 2: `my-app-backend` (Go)
*   **Frontend CI/CD:** Connect Repo 1 to Vercel. Every time you push to the `main` branch, Vercel will automatically build and deploy your site in seconds.
*   **Backend CI/CD:** Connect Repo 2 to Fly.io/Render. Every time you push to `main`, it will compile your Go code and deploy the API.
*   **Environment Variables:** Keep your Neon Database URL and Cloudinary API Keys inside the `.env` files of both your local machine and your hosting providers.

## 6. Migration Plan (When you get traction & funding)
When you outgrow the free tiers, the upgrade path is incredibly smooth:
1.  **Vercel:** Pay $20/month for the Pro plan.
2.  **Go Backend:** Scale up Fly.io instances ($5–$15/month) or move to AWS/Google Cloud via Docker.
3.  **Neon DB:** Upgrade to their $19/month Launch plan.
4.  **Banking Feature:** Introduce **Java (Spring Boot)**, host it on AWS Elastic Beanstalk or Google Cloud Run, and lock it down with strict firewalls so *only* your Go backend can talk to it.
