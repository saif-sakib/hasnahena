# 🏛️ Core Banking Architecture: Final Tech Stack

## 1. Frontend: Web, PWA & Future Mobile (100% Free Software)
This stack ensures a lightning-fast, visually stunning, and highly secure user interface across all devices.

*   **Web Framework:** **Next.js (React)** 
    *   *Why:* Server-Side Rendering hides API calls and business logic from the browser. Built-in PWA support for Android installation.
*   **Language:** **TypeScript** (Mandatory for catching bugs).
*   **UI System:** **Tailwind CSS + Shadcn UI** 
    *   *Why:* Accessible, deeply customizable, and zero bloat.
*   **Future Mobile App:** **React Native** 
    *   *Why:* Shares 80% of the logic and UI components with your Next.js web app.
*   **State Management:** **Zustand** + **React Query** (For caching and securely fetching user balances).

## 2. Backend Microservices: The Engine (100% Free Software)
A dual-language microservices architecture balancing ultimate speed with strict financial accuracy.

*   **API Edge Gateway & Real-time Services:** **Go (Golang)**
    *   *Role:* Handles all incoming web traffic, rate limiting, WebSockets, and instant push notifications.
*   **Core Ledger & Transactions:** **Java (Spring Boot)**
    *   *Role:* Handles double-entry bookkeeping, ACID transactions, interest calculations, and complex financial math.
*   **Internal Communication:** **gRPC** (For real-time synchronous calls) and **Apache Kafka** (For asynchronous event streaming—ensures no transaction data is ever lost during traffic spikes).

## 3. Database & Storage: The Vault (Mixed Free & Paid)
*Here, we use paid managed services. Never self-host a banking database to save money; a server crash could literally erase money.*

*   **Primary Database (Paid / Managed):** **AWS RDS for PostgreSQL**
    *   *Why Paid?* AWS RDS handles automated daily backups, multi-zone replication (if one data center burns down, another takes over instantly), and strict encryption.
*   **Caching Layer (Free Software):** **Valkey** (The free, open-source replacement for Redis). Stores fast-access data like active sessions.
*   **Document Storage (Paid / Cheap):** **AWS S3**
    *   *Role:* Storing encrypted user KYC documents, NID photos, and PDF statements. Highly secure and incredibly cheap.

## 4. Security & Authentication: The Armor (Mixed)
*   **Identity & Access Management (Free Software):** **Keycloak**
    *   *Role:* Handles user logins, Biometrics, Multi-Factor Authentication (MFA), and OAuth 2.0. Completely free to self-host and enterprise-grade.
*   **Secrets Management (Free Software):** **HashiCorp Vault (Community Edition)**
    *   *Role:* Encrypts and hides all database passwords and API keys.
*   **WAF & DDoS Protection (Paid / Mandatory):** **Cloudflare (Pro/Enterprise)**
    *   *Why Paid?* Self-hosted firewalls cannot withstand state-sponsored or massive botnet DDoS attacks. Cloudflare absorbs attacks before they even reach your servers.

## 5. DevOps & Infrastructure: The Foundation (Paid Compute)
*   **Cloud Provider:** **Amazon Web Services (AWS)**
    *   *Region Strategy:* Since you are in Bangladesh, host your primary servers in **AWS ap-south-1 (Mumbai)** or **ap-southeast-1 (Singapore)** for the absolute lowest latency and fastest app loading speeds.
*   **Containerization & Scaling (Free Software):** **Docker + Kubernetes (AWS EKS)**. Automatically duplicates your servers on payday when thousands of users log in at once.
*   **CI/CD Pipeline (Free Software):** **GitLab CI/CD** or **GitHub Actions**.

## 6. Observability & Monitoring: The Radar (100% Free Software)
Instead of paying thousands of dollars a month for Datadog, use this modern open-source stack to track every click and server heartbeat.

*   **Metrics & Dashboards:** **Prometheus + Grafana**
*   **Application Tracing & Logs:** **SigNoz** (A brilliant, free, open-source alternative to Datadog that tracks where an API request slows down or fails).

## 7. Mandatory Paid Integrations (Banking Specifics)
To make this a real, functioning bank, you *must* integrate and pay for these third-party APIs. There are no free alternatives that provide legal compliance.

1.  **KYC & Identity Verification:** 
    *   To legally open bank accounts, you must verify the user's identity. 
    *   *Global:* **Onfido** or **SumSub**.
    *   *Local (Bangladesh):* You will need to integrate with the **Porichoy API** (Bangladesh National ID Verification Gateway) to verify NID cards instantly.
2.  **SMS Gateway (For OTPs):**
    *   For global: **Twilio** or **AWS SNS**.
    *   For Bangladesh: You must use a local aggregator like **SSL Wireless**, **MuthoFun**, or **Reve SMS** for fast, reliable, and cheap domestic OTP delivery.
3.  **App Store Fees:**
    *   Apple Developer Program ($99/year) and Google Play Console ($25 one-time fee) to publish your mobile apps.
